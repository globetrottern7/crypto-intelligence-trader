# M1 Acceptance Criteria

- [ ] Repository and README present.
- [ ] Frontend installs, type-checks and builds.
- [ ] Desktop/tablet/mobile layouts work.
- [ ] PWA manifest is served.
- [ ] Backend starts and `/health` responds.
- [ ] `/api/v1/system/status` reports paper-only mode.
- [ ] PostgreSQL starts via Compose.
- [ ] Frontend calls backend health endpoint.
- [ ] `.env` is ignored; `.env.example` contains placeholders only.
- [ ] Backend tests pass.
- [ ] GitHub Actions runs backend and frontend checks.
- [ ] No fabricated market prices/signals.
- [ ] No live execution functionality exists.
